# 🤖 إيجنت الواتساب الذكي المجاني 100% — نظام القسام

نظام مستقل ومفتوح المصدر يعمل في الخلفية لقراءة الحوالات الواردة من **مجموعة العملاء (أ)** عبر واتساب، ثم حساب المقابل بالبر وتقفيل المئات واستقطاع السنتات آلياً، وتوجيه الكشف فوراً إلى **مجموعة الصرافين والمنفذين (ب)**، مع إرسال إشعار تأكيد فوري برقم المرجع في مجموعة المصدر.

---

## 🌟 الميزات الهندسية:
- **مجاني 100%**: لا يحتاج إلى اشتراك Meta API أو أي خوادم مدفوعة.
- **ربط بروتوكول واتساب ويب**: مسح رمز QR لمرة واحدة وحفظ الجلسة محلياً في `auth_session/`.
- **محرك تحليل ذكي متقدم**: استدعاء `WhatsAppParser.js` و `FinancialEngine.js` للتعرف على أي شكل من الرسائل المجزأة والمتتالية والمرسلة بأي اسم أو رقم.
- **خادم جسر محلي (Bridge Server)**: يبث البيانات لحظياً عبر المنفذ `4124` لربطها بشاشة المتصفح الرئيسية لنظام القسام.
- **حفظ السجلات**: تسجيل كل دفعة في `data/remittances.json`.

---

## 🚀 طريقة التثبيت والتشغيل السريع:

### 1. تثبيت الحزم (مرة واحدة فقط):
```bash
cd whatsapp-agent
npm install
```

### 2. إعداد المجموعات:
افتح ملف `config.json` واضبط:
- `exchangeRate`: سعر المصارفة المعتمد (افتراضياً `48`).
- `sourceGroupId`: معرف مجموعة المصدر (أ) أو اترك `listenToAllGroups: true`.
- `targetGroupId`: معرف مجموعة المنفذين (ب) لإرسال الكشوف إليها تلقائياً.

### 3. تشغيل الإيجنت:
```bash
npm start
```

- سيظهر لك في موجه الأوامر رمز **QR Code**.
- افتح تطبيق واتساب في هاتفك > **الأجهزة المرتبطة** > **ربط جهاز** > وامسح الرمز.
- بمجرد اكتمال المسح، ستظهر رسالة:
  `✅ [تم الاتصال بنجاح بواتساب]: الإيجنت الآن في وضع الاستماع المباشر!`

---

## 🔄 للتشغيل المستمر 24/7 دون توقف (اختياري عبر PM2):
```bash
npm install -g pm2
pm2 start agent.js --name "sharaf-whatsapp-agent"
pm2 save
pm2 startup
```

---

## 🛠️ ملفات الحزمة:
- `agent.js`: المحرك الرئيسي وربط بروتوكول واتساب وخادم الجسر المحلي.
- `formatter.js`: منسق رسائل الكشوف الموجهة للصرافين وإشعارات التأكيد.
- `config.json`: ملف الإعدادات الموحد وأسعار الصرف ونصوص القوالب.
- `data/remittances.json`: قاعدة البيانات المحلية للحوالات المعالجة.
